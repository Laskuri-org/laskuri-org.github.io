Laskuri.org – laskurit ja muuntimet arjen kysymyksiin

Laskuri.org tarjoaa ilmaiset laskurit ja yksikkömuuntimet talouteen, liikuntaan, terveyteen ja arjen mittoihin. Käyttäjätiliä ei tarvita, ja laskenta tapahtuu omassa selaimessasi.

Miten laskurit on tehty

Laskuri.org on staattinen sivusto. Jokainen laskuri on yksi tavallinen JavaScript-tiedosto ilman sovelluskehystä.

  • Laskenta selaimessa

    Kaavat ovat puhtaita funktioita, jotka eivät lähetä syötteitä mihinkään. Raha lasketaan kokonaisina sentteinä, jotta pyöristykset täsmäävät.

  • Testattu tunnetuilla arvoilla

    Samaa tiedostoa ajetaan selaimessa ja testeissä. Yli kaksisataa yksikkötestiä vertaa tuloksia tunnettuihin esimerkkilaskelmiin.

  • Korkotieto Suomen Pankista

    Lainalaskuri hakee Euribor-korot sivuston omasta palvelusta. Jos haku ei onnistu, käytössä on tallennettu noteeraus tai oma korkosi.

// Annuiteettilainan kuukausierä. expm1 ja log1p pitävät tuloksen tarkkana pienillä koroilla.
function annuity(principal, annualRate, months) {
  const r = annualRate / 1200;
  return r === 0
    ? principal / months
    : principal * r / -Math.expm1(-months * Math.log1p(r));
}

Esimerkki on lainalaskurin lähdekoodista. Sivuston lähdekoodi on yksityinen; tämä GitHub-organisaatio kokoaa yhteen Laskuri.orgin julkiset tiedot.

Laskenta pysyy selaimessasi

Syöttämiäsi lukuja ja laskentatuloksia ei lähetetä palvelimelle eikä tallenneta. Lainalaskurin Euribor-haku ei sisällä laskentasi syötteitä. Lue lisää tietosuojasta.
